# 本地待办清单

一个用于学习的极简待办清单静态网页。不依赖框架、不依赖 npm，不调用任何外部网络资源。

## 运行方式

无需安装任何东西。任选一种：

1. 直接打开：用浏览器双击 `index.html`。
2. 本地静态服务器（推荐，避免 `file://` 的存储限制）：

   ```bash
   cd /home/wsr/vibe-projects/first-todo
   python3 -m http.server 8000
   ```

   然后访问 <http://localhost:8000/>。

## 功能

- 新增任务：输入非空内容，按回车或点“添加”。
- 标记完成 / 恢复未完成：勾选任务前的复选框。
- 删除任务：点任务右侧的“删除”。
- 持久化：任务保存在浏览器 `localStorage`，键名为 `todos.v1`，刷新后仍在。
- 状态提示：显示“共 N 条，完成 M 条”；列表为空时显示空状态引导。
- 键盘操作：`Tab` 在输入框、复选框、删除按钮间移动；输入框内按回车提交。所有可操作元素都有可见的焦点样式。

## 验收步骤

1. 打开页面，确认输入框有占位提示、能看到空状态文案。
2. 在输入框只输入空格后提交，确认不会新增，并出现“不能为空”提示。
3. 输入一个任务提交，确认列表出现该项、计数变为“共 1 条，完成 0 条”、输入框清空且仍聚焦。
4. 勾选该任务的复选框，确认文字出现删除线、计数变为“完成 1 条”。
5. 取消勾选，确认恢复未完成状态。
6. 再添加两条任务，删除中间一条，确认列表和计数同步更新。
7. 刷新页面（F5），确认任务与完成状态仍然存在。
8. 删除全部任务，确认重新显示空状态引导。
9. 全程只用键盘走一遍：`Tab` 定位、`Enter` 提交、空格切换复选框。
10. 打开浏览器开发者工具的 Network 面板并刷新，确认除了本地文件外没有任何外部请求。
11. 把窗口缩窄到约 320px，确认无横向滚动、按钮仍可点击。

## 已知限制

- 数据只存在当前浏览器的 `localStorage`，换浏览器、换设备或清理浏览器数据都会丢失，不做云同步。
- 以 `file://` 直接打开时，某些浏览器会限制或隔离 `localStorage`；此时数据可能无法跨刷新保留，建议用上面的本地服务器方式。
- 若 `localStorage` 中数据损坏（非合法 JSON 或结构不符），会回退为空列表，页面不会崩溃，但原数据不会自动修复。
- 任务文本最长 200 个字符，超出部分会被截断。
- 不做登录、注册、后端、数据库、支付、第三方依赖与构建工具，也没有撤销、编辑、排序、筛选等功能。
- 界面语言为中文，未做多语言支持。
